# Mengão Celeste

Tema pessoal para o app do Claude (desktop e celular), misturando Flamengo e Uruguai:

- fundo liso em celeste claro (modo claro) ou quase preto (modo escuro);
- escudo do Flamengo e bandeira do Uruguai pequenos nos quatro cantos, longe do texto;
- respostas do Claude em balão celeste, títulos em vermelho e ações em faixa dourada.

O terminal não desenha temas; ele aparece só nos apps.

## Instalar

No terminal do Claude Code:

```
/plugin install mengo-celeste --marketplace igorss93-star/claude-tema-mengo
```

No app desktop: clique no + ao lado da caixa de mensagem, depois Plugins, Add marketplace com `igorss93-star/claude-tema-mengo`, e então Add plugin.

Como o repositório é privado, a máquina precisa ter acesso ao GitHub configurado (por exemplo `gh auth login` e `gh auth setup-git`).

O escudo do Flamengo é marca do clube; este tema é só para uso pessoal.
